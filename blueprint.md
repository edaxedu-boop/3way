
# Mi Chanchito App Blueprint

## Overview

"Mi Chanchito" is a Flutter application designed to help users manage their personal finances. It allows them to track income, expenses, and debts, providing a clear overview of their financial health. The app prioritizes a visually appealing and intuitive user interface to make financial management a more engaging and less daunting task.

## Style, Design, and Features

### Initial Version (v1.0)

*   **Theme:** A modern and clean theme with support for both light and dark modes.
    *   **Colors:** A color scheme will be generated from a seed color to ensure a harmonious and accessible palette.
    *   **Typography:** Custom fonts from Google Fonts will be used to create a unique and readable text hierarchy.
*   **Navigation:** A bottom navigation bar for easy access to the main sections of the app:
    *   Home
    *   Income
    *   Expenses
    *   Debts
*   **State Management:** The `provider` package will be used for state management, particularly for theme toggling.
*   **Home Screen:** The initial home screen will be a simple placeholder.

## Current Plan

The current plan is to build the initial structure of the "Mi Chchito" app, including:

1.  **Project Setup:** Add necessary dependencies (`provider`, `google_fonts`).
2.  **Theme Creation:** Define the light and dark themes for the application.
3.  **Main App Structure:** Create the main application widget and set up the `ChangeNotifierProvider` for the theme.
4.  **Home Screen:** Implement the initial home screen with a bottom navigation bar.
